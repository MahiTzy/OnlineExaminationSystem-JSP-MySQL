# NOU — Online Examination System

A Java web application project for an online examination workflow.

## Overview
The project uses JSP-based web pages and a MySQL database. Review the source code to identify the implemented user roles, examination flow, question management, and result handling.

## Technology
- Java
- JavaServer Pages (JSP)
- MySQL
- Bootstrap
- Servlet container / Java web runtime required by the project

## Getting Started
1. Install a compatible JDK, MySQL, and a Java web server such as Apache Tomcat compatible with the project.
2. Clone the repository:
   ```bash
   git clone https://github.com/MahiTzy/OnlineExaminationSystem-JSP-MySQL.git
   cd OnlineExaminationSystem-JSP-MySQL
   ```
3. Import the project into a Java IDE.
4. Create the required MySQL database and import the SQL schema/data script if one is included.
5. Update the database connection settings in the application configuration.
6. Deploy the web application to the configured servlet container and open its local URL.

## Database Configuration
Use the connection properties and schema names referenced by the source. Keep credentials local and never commit production database details.

## Development
Test with synthetic users and exam data. Review access control and validation before using the project beyond a local learning environment.
